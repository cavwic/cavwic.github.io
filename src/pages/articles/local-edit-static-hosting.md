这个站点只把本地电脑当作编辑环境。写完文章或更新页面后，代码推送到 GitHub，托管平台再根据仓库内容生成静态网页。电脑关机后，网站仍然可以访问。

## 第一阶段要解决什么

第一阶段只做四件事：发布方案和文章，展示工具，把访问者带到对应的 GitHub 仓库，并为后续的 Skill 下载留好位置。它暂时不需要账号系统、数据库或在线编辑器。

静态站适合这个范围。页面生成后只有 HTML、CSS、JavaScript 和图片，运行成本低，也减少了需要长期维护的服务器组件。

## 内容放在哪里

文章正文与页面代码进入 GitHub 仓库。工具源码放在各自的项目仓库。需要下载的 Skill、压缩包或模板使用 GitHub Releases 保存，这样每个文件都有版本号和更新记录。

网站只做索引和说明。它不复制一份难以同步的源码，也不把家庭 NAS 暴露成公开下载服务器。

## 域名怎样分工

个人主页使用根域名。NAS 继续使用单独的远程访问子域，两者不共享部署环境。等静态托管平台生成正式地址后，再修改根域的解析记录并验证 HTTPS。

## 下一步

先完成首页和内容模板，再创建 GitHub 仓库并进行一次预览部署。预览确认无误后，才切换根域名。这样 DNS 变更不会早于可用的网站。
