## Status

This is personal research and tool practice. I did not use vendor hardware, and this was not a customer procurement project. Public specifications can support candidate screening but cannot replace physical testing.

## Method

I defined the object set from the task, then assigned six visible weight groups: mechanism and actuation, tactile sensing, control interfaces, payload definition, durability and service, and documentation completeness. Users can change every weight. Unknown fields are not filled with a class average; they reduce the evidence-completeness result.

Sensitivity analysis moves each weight up and down to test whether the ordering remains stable. When one candidate leads only under one subjective weight, the tool marks the conclusion as fragile instead of issuing a firm recommendation.

The test design records object, pose, strategy, force threshold, temperature, communication, result, and failure type. Success rates are split by object so an average cannot hide a structural failure.

## Conclusion

Public material is useful for finding differences and missing evidence, not for making a purchase decision. The next step is to convert unknown fields into vendor questions, convert important differences into hardware tests, and review the result with the arm, vision, and task system.
