# Acceptance worksheet

| Area | Record |
| --- | --- |
| One business task | User, current process, input, output and exclusions |
| Data contract | Source, version, authorized roles, refresh and deletion propagation |
| Output contract | Fields or answer structure, citations, units, abstention and corrections |
| Test samples | Sample ID, expected outcome, risk category and reviewer |
| Measurement | Denominator, failure counting, threshold, reproduction and approver |
| Action boundary | Read, write or send; approval, idempotency and receipt |
| Escalation and cost | Owner, stop condition, human correction and failure cost |

Consider ordinary questions, missing evidence, conflicts, stale sources, different roles, malicious document instructions and unavailable dependencies. Adapt to the risk; this is not an exhaustive checklist.
