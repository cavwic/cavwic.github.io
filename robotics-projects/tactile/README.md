# 合成触觉滑移检测与闭环抓力

这是可复现的合成时序学习实验，不是真实传感器采集、真机抓取或硬件性能证明。

## 运行

在仓库根目录运行：

```powershell
robotics-projects\.venv\Scripts\python.exe robotics-projects\tactile\run.py
node scripts/test-robotics-learning.mjs
```

依赖仅 NumPy。结果写入 `public/robotics-lab/tactile/results.json`，训练集/验证集/测试集保存到本目录 `dataset.npz`。浏览器只回放实际计算结果，不假装在线传感或在线训练。

## 方法与边界

1. 单个物体沿竖直方向运动，采样100 Hz、每回合5 s；静摩擦上界为 `mu * N`，滑动摩擦为其0.85倍，带黏性阻尼。`N`表示两侧总法向力。下滑速度大于0.003 m/s定义为参考滑移；累计下滑超过0.08 m定义为滑落。
2. 观测为带噪声的法向力、剪切力、振动。振动是显式依赖滑动速度的合成换能器模型，单位是任意单位，不是加速度计测量。分类器不接收摩擦系数、真值速度、物体位移或未来样本。
3. 8帧因果窗口提取6个特征；仅使用120个训练episode拟合标准化和带L2正则的logistic分类器。30个验证episode选择判别阈值，40个独立测试episode报告逐帧precision/recall/F1和混淆矩阵。禁止把同一episode窗口随机拆入不同集合。
4. 对照是固定3 N抓力、振动RMS阈值0.055、训练分类器。后两者使用完全相同的抓力增减律和上下限，区别仅在报警器。
5. 每个控制方法在nominal、2.5倍观测噪声、未见低摩擦三个条件各运行40个共同随机种子的独立闭环回合，报告滑移超限率（页面简称滑落率）、平均力、每回合峰值力均值、位移、检测延迟。力指标是带噪声的测量值，而非电机指令值，所以测量峰值可能略高于9 N指令上限。延迟从首次参考滑移到之后首次报警，未检测不填零；检测成功数单列。另在相同测试episode种子上分别评估三种条件的逐帧P/R/F1，不重新选阈值。

局限：这是简化1D摩擦参考，未建模接触斑、扭转、真实振动频谱、传感器延迟和夹爪柔顺性；超过80 mm的任务失败预算后，虚拟摩擦接触继续供诊断，不是物体脱离夹爪后的真实掉落过程。学习模型可以利用生成器规律，不能据此宣称对真实材料有相同准确率。测试环境仍由同一模拟器生成。逐帧高F1不保证闭环稳定：同一分类器在低摩擦条件可能检测得很准确，但已来不及阻止物体累计滑移，或受抓力上限限制。

`results.json`保存全量360个闭环回合；`manifest.json`是网页首屏摘要（约0.35 MB），其余轨迹按9个条件/方法分组按需加载。
