# 单关节闭环与辨识实验

状态：浏览器可运行的数值实验；没有连接电机，没有真实测量数据。

入口由网站 Robotics Lab 项目导航提供。引擎：`src/features/robotics-lab/control/engine.ts`，界面：同目录 `panel.ts`。

## 方法

SI 单位。模型 `J qdd = torque + load - b qd - Tc*tanh(qd/0.02) - g*sin(q)`。`g` 为重力力矩幅值，不是重力加速度。控制器为 PID，微分作用于测量，避免设定值微分冲击。执行器有力矩饱和，机械关节有硬限位；限位采用完全非弹性速度投影。2 ms 控制周期，控制周期内力矩零阶保持，动力学采用四阶 Runge–Kutta。

普通积分与条件积分使用同一对象、目标、扰动和步长。条件积分只阻止使饱和继续加剧的积分更新；它不保证所有增益、对象和参考下都更优。可在页面调整参数观察性能退化。不可达目标是特意保留的失败用例，抗饱和不能突破机构限位。

辨识使用固定种子合成多正弦激励；中心差分速度得到加速度，回归 `[qdd, qd, tanh(qd/0.02), sin(q)]` 对力矩。限位附近样本被丢弃。列缩放后解正规方程，报告残差和消元 pivot ratio（不是严格矩阵条件数）；不足激励、秩亏和非物理解会显式失败。这是已知模型上的流程验证，不是独立硬件辨识精度证据。

## 指标

- RMSE：0.5 s 目标启动后到结束的角度跟踪误差均方根，转为度。
- 超调：只在负载扰动前评估阶跃，按阶跃幅值归一化；正弦不报告。
- 调节时间：扰动前进入 ±max(2%幅值, 0.005 rad)，且保持至少 0.25 s；未达到记 null，不把实验结束当作收敛。
- 末段误差：最后 0.5 s 平均绝对误差，不声称真正稳态已存在。
- 饱和占比：整个实验中未饱和指令绝对值超过扭矩限值的样本比例。

## 复现

在网站仓库根目录，Node 22.18+（内置 TypeScript 类型剥离）：

```powershell
node scripts/test-robotics-control.mjs
```

无需额外安装或电机。页面的 JSON 导出含配置、两个控制器全量样本、指标和模拟来源；CSV 导出抗饱和控制器全量样本，所有列带单位。两个策略曲线都在 JSON 内，避免手工抄图。参数改变后点“重新计算”才生效。

11 项测试还包含最小 DOM / requestAnimationFrame 回归：播放中重新计算会取消并清零动画句柄，随后第一次点播放即可继续。该测试检查交互状态，不替代浏览器像素验收。

## 失败与边界

无齿隙、柔性传动、编码器量化、驱动电流环、通讯延迟、热降额和真实摩擦辨识。限位碰撞不用于结构强度分析。拟合数据来自同一种模型，残差小不能证明真实世界适用。实现真实硬件前必须测量惯量/摩擦、连续力矩、供电、电流环和采样延迟，先做低功率台架和独立硬件急停。

方法参考：[MathWorks 条件积分与抗饱和示例](https://www.mathworks.com/help/simulink/slref/anti-windup-control-using-a-pid-controller.html)。本页独立实现，不依赖 MATLAB。
