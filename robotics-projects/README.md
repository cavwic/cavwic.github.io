## 证据边界

这些是实际执行代码的学习实验，不是完成真机部署、掌握岗位能力或取得客户成果的证明。各项目完整范围还包括后续硬件与系统集成，本批不能代替它们：

| 原编号 | 本阶段 | 尚未验证 / 不应声称 |
|---|---|---|
| 1 | 一关节动力学、PID、抗饱和、合成辨识 | 电机、编码器、摩擦回差实测；真实数字孪生标定 |
| 2 | 合成动作 / 摄像头关键点重定向、限位 IK、手型标定与捏合指标 | 人体测量精度、可制造拇指机构、真实执行器及实体手控制 |
| 3 | 安全内核、故障注入、ROS2 包源码与纯逻辑测试 | Ubuntu 虚拟机 colcon / DDS / rosbag2 联调、硬件安全等级 |
| 4 | MuJoCo 自由物体与夹爪接触、实际多次评测和回放 | 五指灵巧手复杂接触与真机抓取 |
| 5 | 合成力/振动、分类器训练与滑移闭环模型 | 真实触觉、材质泛化、真实夹持力控制 |
| 6 | 规范 JSON 检查器、时间/异常/泄漏证据、离线 bag 适配源码 | 真实设备数据验证、原始视频语义检查 |
| 7 | 官方 ACT 在低维二维到达任务上的实际训练与留出评测 | 视觉 ACT、真实机械臂、完整抓放任务、VLA 能力 |
| 8 | 参数搜索与配对工况的仿真鲁棒性实验 | 强化学习训练、系统辨识实测、Sim-to-Real 成功 |

页面所有结果须能追溯到对应源码、配置、种子、原始结果和算法版本。没有结果时显示加载错误，不构造成功率。实验可能揭示某方法更差，应保留该失败结论。

## 展示模型与数据的对应关系

2026-10-21 升级的是几何细节和显示质量，不是新的硬件、物理模型或学习结果。项目 2 保持原样。

- 01 / 03：细化单轴试验架、伺服外壳、轴承、连杆、刻度与线束；同一帧的关节角、目标和安全状态驱动模型。外观不是已制造的 CAD，也未用于重新计算惯量。
- 04 / 08：完整三维回放记录位置、四元数和接触点。指垫、桥及物体尺寸对应原 MJCF；可切换碰撞几何。外壳与滑轨仅为外观层，不参与碰撞，也不改变记录。
- 05：一维合成接触的三维示意，颜色和箭头表示标量抓力，不冒充触觉阵列。下滑超过 80 mm 后停在显示边界，数值继续展示原记录，不虚构落体过程。
- 06：完整有效采样的矢量曲线，自动量程、多关节与逐帧检查；保留时钟倒退、重复时间和缺失维度，不平滑、不重排、不降采样。
- 07：二维任务的 XY 平台示意，路径和目标作等比显示映射；任务单位不是毫米，没有新增受控自由度或训练机械臂。

三维视图支持旋转、缩放和标准视角，采用同源程序几何及 Three.js 材质，不加载远程模型或贴图。总览与纯数据页按需加载，不预先下载三维渲染器。WebGL 不可用时保留二维回放或图表功能。

## 返回与操作历史

八个项目及旧重定向入口均提供「返回上一级」，返回当前语言的实验台总览。每页共用「撤销 / 恢复」工具栏；恢复表示重做已撤销的操作。历史仅在当前页面内存中保留最近 50 步，刷新或重新进入不保留。新操作会清除尚未恢复的分支。

参数输入与拖动合并为一步，项目选择、手动控制、回放定位、模型视角和显示选项可撤销；模型、图表与指标一起恢复。撤销时暂停播放。快捷键为 Ctrl/Cmd+Z、Ctrl+Y 或 Ctrl/Cmd+Shift+Z；文字输入框保留浏览器自身的文字撤销。

自动播放和采集的每一帧不单独入栈；文件下载、基线评测执行、摄像头权限与启动不自动重放。重定向涉及相机的历史恢复后，相机保持暂停，需手动重新启动。撤销设置不会删除之后采集的帧；切换或清空产生的非空记录段保留在本页，并可通过「导出保留记录」下载。保留段不自动丢弃，长会话可能占用更多内存；请在刷新前下载。分段备份再次导入时须取其中一段的 `session` 对象，而不是整个备份容器。

## 查看与运行

现有 `Cavwic-Astro-Preview` 计划任务在用户登录时提供本地预览；本批不增加启动项。必要时 PowerShell 运行：

```powershell
Start-ScheduledTask -TaskName Cavwic-Astro-Preview
```

Node 24（或支持 TypeScript 类型擦除的 Node 版本），仓库已有依赖：

```powershell
node scripts/test-robotics-labs.mjs
node scripts/test-robotics-visuals.mjs
node scripts/test-hand-retargeting.mjs
node scripts/test-hand-calibration.mjs
node scripts/test-hand-runtime.mjs
node scripts/test-hand-visual.mjs
node scripts/test-hand-history-records.mjs
node scripts/package-robotics-labs.mjs
node scripts/build-robotics-labs.mjs
node scripts/verify-robotics-http.mjs
```

独立构建覆盖 18 个中英文实验台页面（总览和八项实验），以及两个旧重定向地址，共 20 页；不把整站其他目录的既有问题混入检查。HTTP 检查需要本地预览正在运行；具体通过情况见 `VERIFICATION.md`，本节仅列出运行方法。

完整复现包同时包含既有重定向代码、测试、说明、第三方许可及同源 MediaPipe 模型 / WASM 资源，不包含本机虚拟环境或用户摄像头录像。构建使用已有本地资源，不自动安装依赖或下载模型；缺少资源时，先查看 `public/hand-retargeting/THIRD_PARTY.md` 和 `scripts/prepare-hand-retargeting-assets.mjs` 中的来源与准备方式。

Python 实验按子目录说明复现。新环境建议 Python 3.12，MuJoCo 3.3.7；训练依赖 LeRobot 0.6.1 和匹配的 PyTorch / torchvision。不要向 ComfyUI、系统 Python 或用户原有环境安装依赖。

本机为了避免重复下载大型 PyTorch，另建 `.training-venv`，通过只读路径复用已经存在的 PyTorch 包；该机器专用路径不会进入复现压缩包。可移植复现应在独立环境正常安装对应依赖。
