# 发布风险审计

当前结论：**仅适合本地审阅，不批准发布。**

## 已采用的边界

- 可以保留雇主名称、职位职责和任职时间。
- 客户名称、地点、金额、内部接口、事故细节、原始标书、内部截图、联系人和第三方个人信息不进入网站。
- 不使用前雇主、客户或厂商 Logo。
- HTML 只允许公开邮箱，不展示电话。
- 真实经历、个人实践、公开资料研究和分析判断分开标注。
- 本地公开版简历候选稿不替换 `public/downloads/陈文聪简历.pdf`。

## 自动检查

`scripts/audit-content.mjs` 扫描手机号、特定客户名、金额与内部材料提示词，并检查内容数量、来源完整性和引用 ID。

## 发布前仍需人工确认

1. 逐篇确认是否触及劳动合同、保密协议或第三方授权限制。
2. 检查简历候选稿的邮箱、时间、雇主和成果表述。
3. 抽查所有产品页面在发布当天仍可访问，且关键字段未过 90 天。
4. 检查截图、PDF、下载包和工具示例是否含本机路径或个人信息。

此流程用于降低风险，不替代律师意见。若现有协议要求更严格，以协议为准。
