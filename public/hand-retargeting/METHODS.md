# 灵巧手动作重定向实验

版本：2026-10-20，拇指远端独立旋前与指腹朝向修正版（运动链 v2）。个人实践；没有真实机器人控制、接触物理、自碰撞检测或工业交付验证。

## 环境与入口

- Windows / macOS / Linux，现代 Chromium 浏览器及 WebGL 2。摄像头是可选项；合成实验无需任何硬件。
- Node.js 24（数值测试直接导入 TypeScript）、现有 Astro 静态站。
- Three.js 0.186.1、MediaPipe Tasks Vision 1.1.0；版本锁在 package-lock.json。
- 在网站目录运行 `npm install`、`npm run prepare:hand-retargeting`、`npm run test:hand-retargeting`。
- 开发预览：`npm run dev -- --host 127.0.0.1 --port 43201`，访问 `/tools/hand-retargeting`；英文 `/en/tools/hand-retargeting`。
- 当前电脑复用已有 `Cavwic-Astro-Preview` 计划任务，不新增启动项。本版本不依赖 VMware、ROS、CUDA 或后端服务。

## 输入与模型

模型是自定义教学手，不代表真实产品，共20自由度。四指各为展收、MCP/PIP/DIP屈曲；拇指为CMC对掌、CMC掌骨屈曲、MCP/IP屈曲。先移动掌骨，再在MCP之前施加与对掌耦合的独立远端旋前，随后MCP/IP沿旋前后的局部轴屈曲；不能让整根拇指继续复制四指的同一屈曲平面。掌坐标x为小指侧到食指侧，y为腕到中指基座，z为掌向。拇指远端正屈曲方向由当前对掌姿态决定，不要求每个关节都把指尖沿全局+z推动。该运动链仍是教学近似，不是测量得到的解剖学模型。

本次纠正了此前验证的缺口：旧合成参考虽有约8mm指尖间距，但两指的弯曲凹侧可能背离对方。同一套FK生成输入再自测，不能排除这类建模错误。新版同时检查模型指腹相向，并加入非FK生成的手工掌向坐标和屈曲方向用例。原Right/Left掌法线符号复核后保留，不通过全手z翻转来补偿拇指关节轴。

21点顺序与 MediaPipe 一致：腕点0，拇指1–4，食指5–8，中指9–12，无名指13–16，小指17–20。长度米、角度弧度。可下载模型参数检查各指骨长、安装方向及关节限位。

合成动作由另一套不同骨长的 human-like 模型生成，**不是录制真人，也不是机器人原样FK回放**。当前动作包括张手、握拳、捏取、指向、展指、连续屈伸和故意超出范围的压力样本；名称用于教学，不声称符合解剖学或指尖已物理接触。

摄像头由已有 MediaPipe 模型估计 worldLandmarks（米）。本项目实现的是后续坐标变换、运动学、重定向、限位、输出平滑及评测，不是自研视觉模型。仅识别一只手，预览镜像不改变推理原图。首次真人验证请正对镜头，从张手到缓慢屈指；检查左右手及掌法线方向，必要时继续校准，不把相机估计当测量真值。

## 计算链

1. 腕点为原点，中指基座方向为掌局部纵轴，食指/小指基座差向量经正交化为横轴，叉积为掌法线。左手规范为右手模型。
2. 按掌宽缩放到机器人模型。它是比例匹配，不是相机标定或真人尺寸测量。
3. 各指基座平移对齐。`getRobotTargets()`返回位置拟合目标；不把目标偷偷投影到可达空间。额外保留分指缩放和基座平移之前共同掌坐标中的`tip4 − tip8`作为捏合目标，不能用对齐后的指尖距离冒充人手间距。
4. 基线根据各骨段的方向和相邻夹角提取关节角，采用单位增益映射；与IK共享限位开关。
5. IK 使用解析位置雅可比、阻尼 Gauss–Newton、每指4×4及拇食指8×8耦合求解、限位投影与目标下降线搜索。目标包括指尖及中间关节残差、微弱姿态正则、相邻帧正则，以及可关闭的拇食指相对向量和距离约束。关节位于限位且方向指向限外时冻结对应自由度，未放宽原限位。
6. 输出可选一阶指数平滑，`alpha=1-exp(-dt/tau)`。开启限位后对最终平滑输出再次投影。平滑降低变化幅度，也带来滞后；不保证所有动作更准。
7. 用最终输出重新做FK，计算与可见目标一致的残差。只记录实际更新或尚未完成的输出过渡；过渡帧标为 `command-settling`。

这不是全局最优求解器，也没有碰撞安全保证。`best-effort`仅说明有剩余误差，不证明目标数学上不可达；原始IK状态与实际平滑后输出指标分别记录。多目标间存在权衡：捏合改善时，位置残差可能增加。

## 手型标定与参数分区

参数按输入来源、合成干预、手型标定、输出与进阶参数分区。噪声和XYZ偏移只对合成输入有效；相机/导入输入时隐藏并禁用，不会被旧合成参数污染。

相机模式先确认“实际右手/左手”，不是画面左右或模型自动分类；预览镜像只影响显示。依次选择张手、握拳、捏合，逐阶段点击采集并保持姿势，每阶段至少20有效帧且覆盖250ms，再保存标定。静态姿势可以重复采新帧，同一帧不能重复计数。无手、异常骨长、错误姿势或左右手不一致不会计入有效帧。

标定保存固定多帧掌宽尺度、分指长度比例及三阶段姿势/屈曲统计，使用median/MAD排除异常估计。它改善的是形态与尺度匹配，不是相机内外参标定，也不是将角度端点强行映射到机器人限位。数据仅保存在当前浏览器，支持JSON导入/导出和明确清除。标定按来源和实际手别隔离；相机、导入、合成不能混用。world导入需明确手别才能采集；已归一化palm回放不能再次标定。

当前标定格式为version 2，记录`modelId`。旧版标定不会静默套用；原浏览器数据仍保留，并提供“导出旧版标定备份”。旧数据需重新采集才能应用到新版运动链。新实验记录也带`modelKinematicsId`，拒绝直接重放旧运动链的实验记录；原文件不被删除，可另导入保留的原始world关键点重新处理。

“用合成数据验证流程”仅验证三阶段计算与界面，始终标记synthetic，不能称为你的真人标定。保存后选择应用，页面重新计算；不支持跨手别/来源自动迁移。

输入滤波是一阶时间常数（默认30ms），只消费新帧；输出平滑独立控制。捏合权重为无量纲，页面默认3，0关闭；提高权重可能牺牲其他位置残差。纯算法API默认1.5；页面评测和导出报告明确记录实际权重。

## 指标与固定实验

- 平均/最大指尖残差：5个指尖到目标的欧氏距离，毫米。
- 关节越界：实际输出超出模型限制的关节数，允许关掉限位观察差异。
- 求解耗时：当前设备 IK 执行时间，受浏览器、负载和硬件影响，不是保证的控制周期。
- 输入/输出捏合距离：共同掌坐标内拇食指关键点中心间距；距离误差为两者差的绝对值，相对向量误差同时反映距离与方向。不是指腹接触或抓取成功率。
- 模型指腹相向：指腹法线与指向另一指尖的单位向量的点积（两指分别计算，范围-1～1）；接近捏合时显示，正值表示朝向对方半球。它只检查模型几何，不是测量真人指腹或真实接触。
- 静止输出抖动RMS：最近约1秒至少12帧/500ms，全部输入点近似静止时显示5个输出指尖相对均值的RMS；运动、采样断档或不足帧显示“—”。不是追踪准确度。
- 采样到指令耗时：主线程开始取相机位图到关节指令计算结束，包含等待与推理，不包含传感器曝光和屏幕显示，不能称为端到端感知延迟。
- 无效追踪帧比例：已完成视觉推理结果中无手或退化输入的比例；不含采集跳帧、推理超时或渲染帧。非相机输入不显示。
- 固定评测：种子42；6类常规合成动作各36帧（216帧）；范围压力样本另24帧、单独统计。不应用个人标定、输入滤波或输出平滑，保留IK时间正则并记录当前捏合权重。
- 页面评测在独立 Worker 重新运行，不读取预先填写的分数。完整报告包含平均/P95误差、耗时及越界计数。压力测试不混入常规动作的汇总平均。
- `npm run test:hand-retargeting`检查解析雅可比与中心差分、旋转/平移/尺度归一化、左右手、可达/超出长度目标、限位开关、噪声确定性、非法输入及命令限速。FK→IK测试只是数值自检，不能证明真人泛化。
- `npm run test:hand-calibration`检查多帧、姿势门限、异常值、来源/手别与序列化；`npm run test:hand-runtime`检查输入滤波、静止窗口与追踪统计。新合成闭合参考约8mm关键点间距，不代表真实指腹已接触；这些测试都不能替代真人摄像头验证。
- `npm run test:hand-visual`检查完整FK旋转到外壳/指腹的映射，覆盖直拇指的轴向旋转与弯曲连续性。渲染不再从21点骨段叉积猜轴向roll，也不强制将指腹翻回全局+z。掌面/掌背视图可直接核对同一关节状态。

## 操作与导入/导出

先选动作，点击播放；再比较两种方法。选择手指可修改XYZ偏移，也可直接拖动右侧彩色目标点。五指在输入关键点、目标和摄像头叠加中使用一致颜色。打开噪声与输出平滑观察变化，切换“超出范围”看残差保持可见。

机器人外观为原创程序生成的倒角掌壳、分节指骨、金属关节、指腹和腕部固定座，全部随原有FK端点更新。它不是某款商业手的URDF/CAD，也不是验证过的可制造结构或碰撞几何；提高网格细节不会提高关键点测量精度。“透视运动链”可检查外壳与21点骨架的对应关系，正面/斜侧/自由旋转用于检查姿态。

导出保存最近最多5000条本地记录，包括输入点、输出关节、两种算法指标、原始IK解、参数、时间和求解状态。相机图像不保存、不上传。原始IK状态不用于宣称平滑后输出收敛。

导入格式（JSON，不超过128MB、5000帧；时间非负且单调）：

```json
{"version":1,"coordinates":"palm","provenance":"synthetic example","frames":[{"time":0,"points":[[0,0,0]]}]}
```

示意中的points必须替换为**完整21个有限三维点**；`palm`为已归一化掌坐标米，`world`为原始世界关键点米（另可设置`handedness: "Left"`）。导出文件以`inputProcessing: "processed"`标记已处理输入，回放时不再次输入滤波，并保留原人手点和捏合目标；重定向仍使用当前算法参数重新求解，不是已录关节命令的原样执行。导入来源由用户提供，网站不验证其真人/真机真实性。

## 摄像头与验证边界

只有点击“启用摄像头”才请求权限。推理在 Worker，最多一个在途图像帧；停止时释放设备和Worker；无手、退化掌坐标、过期帧与设备断开均停止更新并保持上次姿态。localhost或HTTPS通常可调用相机，普通局域网HTTP/受限iframe可能不可用。

预览位于主舞台，与机器人输出并列；窄窗口自动上下排列。支持放大摄像头画面和21个二维关键点叠加。视频与关键点叠加同时做镜像显示，控制仍使用未镜像的世界坐标。采集优先请求1280×960/30fps，设备可以返回较低分辨率，以界面显示的实际尺寸为准；高分辨率请求不是精度或帧率保证。视频使用contain保持完整画幅，不裁掉指尖。

“检查本地视觉模型”只对空白合成图像执行一次实际推理，验证模型/WASM/Worker可运行；不能据此宣称真人追踪、左手镜像或遮挡稳定性已经实拍验收。暂无摄像头时也可检查这个运行链。

2026-10-15求解改进：在接近直链、局部迭代停滞、指尖仍有残差且目标未超出链最大长度时，最多尝试两个确定性小屈曲初值；按同一目标函数选择较优结果。步长上限按整个Gauss–Newton方向等比例缩放，避免分量裁剪改变下降方向。回归测试包括压缩的直链目标；这仅改善局部优化稳定性，不保证全局最优。原始目标、骨长和限位没有为降低显示误差而修改。

公开展示时可说“实现并理解运动学重定向与可复现实验”，不要说“已经部署到真实灵巧手”“已验证毫米级真人精度”或“具备抓取安全保证”。个人学习仍需要亲自理解、修改参数和复现实验；自动生成代码不等于已经掌握。
