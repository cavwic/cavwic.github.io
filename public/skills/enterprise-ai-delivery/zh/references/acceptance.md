# 验收工作表

| 项目 | 填写内容 |
| --- | --- |
| 一个业务任务 | 用户、现有流程、输入、输出、不在范围内 |
| 数据契约 | 来源、版本、授权角色、更新时间、删除传播 |
| 输出契约 | 字段或回答结构、出处、单位、拒答和修订方式 |
| 黄金样本 | 样本标识、预期结果、风险类别、复核人 |
| 指标口径 | 分母、失败计数、阈值、复测步骤、批准人 |
| 操作边界 | 只读 / 写入 / 外发、审批、幂等、回执 |
| 接管与成本 | 负责人、停止条件、人工修订与失败成本 |

建议测试：正常问答、缺资料、相互冲突、过期资料、不同角色、文档内恶意指令、下游超时。按真实风险增减，不把这张表当作穷尽清单。
