# 状态与恢复工作表

每个有副作用的节点记录：事件标识、业务主键、尝试次数、审批记录、请求摘要、目标记录标识、最终状态和下一责任人。日志不保存密钥或不必要的原文。

| 测试 | 要确认的结果 |
| --- | --- |
| 同事件重放 | 不重复创建目标记录 |
| 写入成功后响应丢失 | 对账后返回已有回执 |
| 审批被拒绝 | 不写入，状态明确结束 |
| 两个子项只成功一个 | 已完成项不重复执行 |
| 接口持续不可用 | 达到限次或截止时间后接管 |

恢复记录：失败节点 / 已产生副作用 / 已核实证据 / 允许恢复动作 / 审批人 / 实际执行结果。没有实际证据的格子留为待确认。
